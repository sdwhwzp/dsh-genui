# Harness 0.1.6 command claims and saved fences

The `/panel` claim carries the catalog name `panel` and the inserted `/panel ` token. Harness 0.1.6 uses the name for command identity and the token for argument extraction; menu selection and direct Enter produce the same claim.

The fork retains saved itinerary aliases (`hero.number`, `steps[].content`, `keyvalue.items[].label`), recoverable fence syntax, and DOM diagnostics. Upstream field-validation fixtures must use invalid values rather than these supported aliases. A valid saved reply renders on streaming completion and replay without modifying persisted Session messages.

Normal fences remain direct output. `validate_dsh_ui` provides repair diagnostics for failed fences and unusually large bodies; the system prompt and bundled skill preserve this behavior while adopting upstream language and component-field guidance.
